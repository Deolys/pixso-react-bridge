## Что проверено реальными инструментами

Исполнялись Node MCP/CLI, файловое хранилище, контроль хешей, очереди процессов, таймауты, повторные попытки, разделение и сборка виджетов, TypeScript, React, Vite и Chrome через Playwright. ZIP экспортёра проверен по CRC32; код экспортёра исполнялся с тестовым Pixso API. Отдельно проверены длинные пути Windows, недопустимые пути ассетов, повреждённые результаты, SHA эталона в captureHash, изменение транзитивной зависимости и защита пользовательских изменений. Браузерный тест содержит девять сценариев; запуск в этой среде не был пропущен.

## Что моделировалось

В корпоративные Pixso и GigaCode доступа нет. Pixso API в тестах моделируется; процессы GigaCode заменены [тестовым работником](../tests/mock-worker.mjs). Поэтому успешный transfer подтверждает работу конвейера, но не качество ответов корпоративной модели и не совместимость с любой версией Pixso.

Визуальные эталоны созданы из независимо написанного HTML в [scripts/demo.ts](../scripts/demo.ts) и [scripts/demo-data.ts](../scripts/demo-data.ts). Во втором демо карточка отдельно отрисована без хоста; снимок экрана не обрезался. Это отдельная реализация тестового экрана, а не PNG из реального Pixso и не снимок сгенерированной React-страницы. Установленный Chrome делает оба снимка. В рабочем переносе эталон берётся из Pixso либо полного автономного экспорта.

Реальный макет, шрифты и целевой проект не предоставлены. Их перенос нельзя считать проверенным этим демо. При подключении runtime проверяет доступность источника, целостность выгрузки, TypeScript и каждый экран; неполные данные и провал проверки оставляют `complete: false`.

## Повторение

В распакованном исходном ZIP с Node.js 22.12+:

```text
npm ci
npm test
npm run demo
npm run demo:data
```

Для демо нужен установленный Chrome либо Chromium Playwright (`npx playwright install chromium`). Результаты появятся в `output/demo` и `output/demo-data`. Для реального подключения следуйте [README](../README.md), [контрактам Pixso](pixso.md) и [настройке GigaCode](gigacode.md).
